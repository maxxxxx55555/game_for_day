# Heirs of Fortune 2.0.0

## English

Complete EN/RU presentation, stable saved event identities and live language switching;31 events/93 decisions, currencies with0.35% each-way spread, inflation, businesses, dynasty and persistent victory/defeat scenes. Fixed integer-cent money and validated exact-float metadata preserve valid profile round trips.

Four distinct background moods and two musical finales, actual Gemini/Lyria provenance, independent Master/Music/SFX/UI controls, curated illustrations and licensed fonts, reduced motion, loading tips and credits. Original licenses and provenance are retained byte for byte. The release is Windows x86_64, built with Godot4.7 Stable using its compatibility renderer.

Download `HeirsofFortune-Windows-2.0.0.zip`, extract the whole archive and run `HeirsofFortune.exe`. Keep the supplied data pack, README and license folders together. Verify the ZIP against the separately supplied SHA256SUMS file. Sources open in Godot4.7; private encrypted export keys and templates are not public source dependencies for editor play.

Save compatibility: protected1.4.0 profiles load with progress intact, Russian copy and the original installation key. Legacy folder names are unchanged.
Back up the entire closed-game profile before upgrading; include its local key and guard files. Iron-mode death intentionally prevents backup rollback.

Release hardening includes signed bounded saves, exact finite numeric metadata, atomic writes, authenticated known-good recovery, critical-data manifest and compiled trusted fallback, read-only integrity safe mode and encrypted public packs. Public executables physically omit the verifier and reject QA arguments. Private QA requires a compiled feature and `GAME_QA=1`; it is not distributed.

Acceptance: All31 events (16 external +15 inline),93 decision layouts and606 keys are covered. 46 rendered Godot invocations passed in each locale, plus Python byte/export/isolation/audio contracts. All49 warning categories are enforced on27 shipping scripts. 50 complete seeded lives, a1813.547-second rendered soak and three exact native victories plus defeat passed. On the tested host the dashboard became ready in2668ms;240 animation samples had16.736ms median and20.346ms p95 frame time.

Full logs, raw seeded/soak results, real-engine galleries and exact public/private pack digests are in the release evidence. Both source locales and native routes report no unexpected errors. Negative/rejected diagnostic runs remain separately labelled. Historical Windows audio-device invalidation was reproduced/recorded separately; three retries passed and final quiet suites used Dummy audio, while audio assets/routing were checked by dedicated tests.

Limits: this is a stylized offline indie game, not an AAA-scale production. Automated tests on one host are not an independent human playtest or universal hardware certification. Offline integrity and encryption do not prevent a device owner from patching code or extracting local keys. The portable executable is not Authenticode signed. Android artifacts are omitted in this cycle because the emulator cannot boot on the host. No Android runtime PASS is claimed. Edition exclusions are explicitly listed in README and the promise matrix.

## Русский

Полная локализация RU/EN и смена языка без потери события.31 событие и93 решения, бизнес, династия, валюты со спредом0,35% в каждую сторону, инфляция и отдельные сцены победы и поражения. Деньги хранятся в целых центах; проверяемые точные числовые метаданные сохраняют корректность профилей.

Четыре музыкальных настроения и два финала с реальным происхождением Gemini/Lyria, независимые уровни звука, проверенные иллюстрации и шрифты, уменьшение анимации, подсказки загрузки и титры. Лицензии сохранены исходными байтами.

Распакуйте весь `HeirsofFortune-Windows-2.0.0.zip` и запустите `HeirsofFortune.exe`; оставьте файл данных и лицензии рядом. Сверьте SHA256 архива с отдельным файлом контрольных сумм. Сохранения 1.4.0 проверены с прежним ключом установки и прогрессом. Перед обновлением скопируйте всю папку профиля закрытой игры вместе с ключом и защитными файлами.

Проверки: 46 запусков Godot на каждом языке,112 ячеек механик,50 полных жизней,30,23 минуты нагрузки,три нативные победы и маршрут поражения.
Сохранения подписываются и проверяются; запись атомарная, резервная копия аутентифицируется. Манифест данных и встроенный доверенный снимок включают безопасный режим только для чтения. Публичный архив зашифрован и не содержит QA-верификатор.

Ограничения: локальная защита не делает офлайн-игру невзламываемой; автотесты на одном ПК не гарантируют отсутствие всех возможных ошибок. Переносимый EXE без Authenticode. Android в этом цикле не выпускается: эмулятор на хосте не запускается. Масштаб AAA и сертификация всех устройств не заявляются. Границы контента перечислены в README и матрице обещаний.
