# Heirs of Fortune 2.0.0

## English
Complete live Russian/English presentation with 585 catalog keys, stable saved event identities and all 93 decision layouts. Four distinct Gemini/Lyria mood compositions, two 20-second musical finales, independent Master/Music/SFX/UI levels, reduced motion, functional credits and coherent application icons. Existing protected profiles and legacy user-data directories remain compatible.
Extract the complete Windows ZIP and launch HeirsOfFortune.exe. Select Russian or English on the initial screen or in settings. Existing1.4 profiles retain their legacy user-data directory and installation integrity key; back up the entire profile before upgrading. New source/music/credits/comfort regressions supplement the unchanged core gameplay checks. Published evidence and exact native/Android results accompany the release report.

Original supplied music remains byte-identical under its descriptive filename. All five new recordings were actually generated through the supported Lyria RealTime API; no synthesized fallback is claimed as Gemini. Each game ships only its own prompts/recordings and provenance. Full-track REST generation was quota-blocked; initial streaming transport failures were retried successfully. Shared build tooling is allowlisted by design. Public Git history and earlier releases are immutable.

Windows is portable and unsigned. Automated local testing does not replace human playtesting on all hardware. Offline authenticated saves and backups provide tamper evidence and recovery, not invulnerability. The Android APK is development-signed and is not a Google Play production artifact; emulator verification does not certify physical ARM devices.

## Русский
Полная русская и английская локализация, выбор языка без потери текущего события. Разные композиции для четырёх настроений, музыкальные финалы, четыре уровня звука, настройка анимации и экран авторов. Каталоги старых сохранений сохранены.
Распакуйте весь Windows-архив и запустите HeirsOfFortune.exe. Язык выбирается на первом экране и в настройках. Перед обновлением сохраните весь профиль вместе с ключом целостности. Старые каталоги данных не переименованы.

Исходная музыка сохранена, новые записи действительно получены через Lyria RealTime; файлы, промпты и хеши указаны в каталоге происхождения. Локальные автоматические проверки не заменяют проверку человеком на всех устройствах. Windows-файл не подписан Authenticode. Защита локальных сохранений не является абсолютной защитой от взлома. Android APK подписан ключом разработки и предназначен для предварительной проверки на эмуляторе, не для Google Play.
