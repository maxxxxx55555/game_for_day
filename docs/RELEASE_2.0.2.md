# Heirs of Fortune 2.0.2 — release candidate

The birth card now includes a subdued, decorative crop of the game’s existing city illustration above the country data. The illustration is fictional and does not depict the selected country. Simulation, saves and the soundtrack are unchanged.

This candidate is not a release until fresh bilingual tests, export and native checks, full seeded routes, legacy compatibility, gallery review, measured stability, exact-head CI and artifact checks pass. Existing 2.0.1 release assets remain unchanged. Windows x64 only; owner play and listening checks remain required before announcement.

## Русский

На экране рождения добавлена декоративная иллюстрация из игры; она вымышленная и не изображает выбранную страну. Игровые правила, сохранения и музыка не менялись. Публикация возможна только после полного повторного тестирования.
